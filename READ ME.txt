This is a small website which features the Top 5 fast food restaurants in Jamaica which are KFC, Pizza Hut, Burger King, Tastee Patties and Domino's. Each restaurant has a short background, menu highlights a video for the restaurant and a link to the menu prices.

CONCEPT AND AUDIENCE
This site is for people mainly tourists who want to check out the best fast food places in a quick and easy way. The information they will receive is background information, the menu, a video ad and where to check prices. The concept is based on the approved Kingston Eats idea (food discovery), widened to fast food across Jamaica with a green gold and black theme.


PAGES
Home (index.html): Navbar Hero banner, carousel, filterable restaurant cards, quick facts table, and an accordion with full details.
Contact Us (contact_us.html): Navbar Contact form with JavaScript validation.
Confirmation (confirmation.html): Navbar Thank-you page that greets the person by name.
About Us (about_us.html): Navbar About the site, mission and values.

BOOTSTRAP COMPONENTS

Bootstrap JavaScript components (3):
1. Collapse (navbar toggler): the navbar collapses into a menu button on small screens.
2. Carousel: the "A Taste of Jamaican Fast Food" slideshow on the home page.
3. Accordion: the "Full Details" section, one collapsible item per restaurant. The "View details" button on each card opens the matching accordion item using Bootstrap's JavaScript (bootstrap.Collapse).
 
Bootstrap features used: responsive navbar, container and grid (row, col-*), cards, buttons, table (table-striped, table-responsive), form controls with validation feedback, alerts, badges, the ratio helper for the videos, and spacing and responsive utilities.




JAVASCRIPT CONCEPTS (js/app.js)
Variables (const, let): "const restaurants" never changes. "let selectedCategory" changes when a filter button is clicked.
 
Data types: Strings (name, category), numbers (rank, yearOpened) and booleans (hasJerk).
 
Array: "restaurants" holds all five restaurants.
 
Objects: Each restaurant is an object with related properties.
 
Conditions :describeAge() handles restaurants with no known opening year. The "Jerk option" badge only shows when hasJerk is true. The form checks use conditions too.
 
Functions: describeAge, buildCard, showRestaurants, createFilterButtons, buildTable, openDetails, trackActivePage, validateContactForm.
 
Iteration: for…of loops build the cards, categories and table rows. forEach creates the buttons and updates the nav links. 
NOTES: The for...of loop is a tool in JavaScript used to step through a collection of data, item by item, and look at each value directly
 
DOM selection: getElementById, querySelector, querySelectorAll. 
NOTES: DOM Selection in JavaScript is the process of targeting specific HTML elements within the Document Object Model (DOM) so you can manipulate their content, styles, or attributes.
 
DOM modification: innerHTML, textContent, classList, createElement, appendChild.
NOTES: DOM (Document Object Model) manipulation allows JavaScript to dynamically change a webpage's content, structure, and styling without requiring a page reload.

Events: Filter button clicks, "View details" clicks, form submit and reset, and the jQuery keyup event.



INTERACTIVE FEATURES
- Category filter: buttons (All, Chicken, Pizza, Burgers, Patties) change which cards are visible and update the "Showing X of 5" count.
- View details: opens the matching accordion item and scrolls to it.
- Active page tracking: the navbar highlights the page you are on.
- Table search (jQuery): typing in the search box hides table rows that do not match.



 CONTACT FORM AND VALIDATION
The form on contact_us.html is handled by a JavaScript submit event listener (event.preventDefault()). It reads the values with value and checks:
- Name: at least 2 characters
- Email: matches an email pattern
- Message: at least 10 characters
 Invalid fields get a red border and an error message, and a warning alert appears at the top. When everything is entered correctly, the person is then sent to confirmation.html, which greets them by the name they entered.




JQUERY
jQuery was used for the live search above the Quick Facts table:
    $("#tableSearch").on("keyup", function () {
        const searchText = $(this).val().toLowerCase();
        $("#factsTable tbody tr").each(function () {
            const matches = $(this).text().toLowerCase().indexOf(searchText) > -1;
            $(this).toggle(matches);
        });
    });
